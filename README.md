## Gambaran umum

PixelPay merupakan demonstrasi desain website bisnis digital yang menyajikan informasi layanan, pilihan paket, proses pemesanan, dan pertanyaan umum melalui antarmuka responsif.

## Fitur antarmuka

- Navigasi dan penyajian paket layanan.
- Formulir, informasi pemesanan, dan FAQ.
- Pilihan tampilan serta bahasa.

## Teknologi dan struktur

HTML, CSS, dan JavaScript; `index.html` merupakan halaman utama, `css/` menyimpan gaya visual, dan `js/` menyimpan logika interaksi.

## Menjalankan secara lokal

```bash
git clone https://github.com/lamberthrumpaidus/pixelpay.git
cd pixelpay
python -m http.server 8000
```

Buka `http://localhost:8000/` melalui browser. 

## Batasan

PixelPay adalah prototipe antarmuka, bukan layanan transaksi yang telah diverifikasi. Integrasi pembayaran, keamanan transaksi, dan pemrosesan pesanan tidak boleh dianggap aktif tanpa implementasi dan pengujian yang sesuai.
