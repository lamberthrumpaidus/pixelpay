## 📌 Deskripsi Project

**PixelPay TopUp** adalah landing page untuk konsep bisnis digital berbasis layanan **top up game online**. Project ini dibuat sebagai tugas mata kuliah **Digital Business** dengan tujuan merancang halaman promosi yang menarik, informatif, dan mampu menjelaskan nilai utama dari sebuah bisnis digital.

Landing page ini menampilkan konsep layanan top up game yang cepat, aman, transparan, dan mudah digunakan oleh pengguna.

## 🧠 Konsep Copywriting

Landing page ini menggunakan pendekatan **AIDA** dan **PAS**.

### AIDA

- **Attention:** Headline “Top up game anti ribet, saldo masuk lebih cepat.”
- **Interest:** Penjelasan layanan yang cepat, aman, dan otomatis.
- **Desire:** Menampilkan manfaat, paket harga, testimoni, dan kemudahan proses.
- **Action:** Tombol CTA seperti “Mulai Top Up” dan “Top Up Sekarang”.

### PAS

- **Problem:** Proses top up lama, harga tidak jelas, dan bukti transaksi sulit dilacak.
- **Agitate:** Pengguna membutuhkan layanan yang cepat dan transparan.
- **Solution:** PixelPay TopUp menyediakan sistem order, bayar, dan tracking dalam satu halaman.
